# cGP 收敛防护夹具

32 个 2×2 标准单元、一个 40×40 可移动宏、32 个零面积独立固定锚点，core 为 92×92，46 行、行高 2。配置使用密度 0.5、目标 0.10、fixed λ、2000 轮上限，filler 种子 3；线程数 1 用于快速回归。输入已固定，不依赖测试时随机生成。

冻结参考和默认算法均收敛；仅在 cGP 关闭动量的独立候选上，mGP 相同，但 cGP 从 τ≈0.090636 的正常结果退化为 τ≈0.590026 的停滞结果。候选的普通 CLI 仍正常完成流水线，验收测试负责拒绝这类新增不收敛，保持“正常停滞不是运行时异常”的契约。

这是**否决候选的反例**，不是两个 newblue4 的根因缩微复现。测试同时固定 cGP 自动选择的 32×32 网格，防止通过缩粗网格绕过问题。数据源和两版运行证据保存在 `results/m3-debug-20261113/fixture-search/unique/n32-s3/`；`test_cgp_convergence.py` 在冻结参考及默认控制 CLI 上通过、在被拒绝候选上失败。
