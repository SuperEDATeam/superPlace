## 0. 使用方式

**给 Agent 的指令模板**：

> 阅读 `work_report/05-开发执行规范.md`。实现其中 §5.X 描述的模块。

1. **§1 铁律不可协商。** 任何与铁律冲突的实现都必须重写，即使功能正确。

3. **§7 的验证判据是完成的定义。** 代码能编译、能跑 ≠ 完成；
   必须通过对应的验证判据。

## 1. 铁律：违反即返工

这 8 条源自 [01 §4](01-架构设计与技术选型.md) 的八个关键决策，此处转写为可机械检查的规则。

### 铁律 1：数值内核不得认识"布局"

`src/numeric/` 下的任何代码**不得** `#include` `db/` 下的任何头文件，
不得出现 `Module`、`Net`、`Pin`、`PlaceDB`、`macro`、`filler`、`cell` 等词。

```cpp
// ❌ 禁止
void solvePoisson(const PlaceDB& db, std::vector<Bin>& bins);

// ✅ 正确
void solve(BinGridSpan density, BinGridSpan phi,
           BinGridSpan field_x, BinGridSpan field_y);
```

**检查方法**：`grep -rE "PlaceDB|Module|Net\b|macro|filler" src/numeric/` 应为空。

### 铁律 2：坐标只有一种约定

- `PlaceDB` **只存中心坐标**，类型 `float`（见铁律 3 说明）。
- 左下角 / 右上角只能通过 `llx(i)` / `urx(i)` 等派生函数获得。
- 左下角 ↔ 中心的换算**只允许在 `src/io/bookshelf_*.cpp` 中出现**。
- Y 轴翻转**只允许在 `src/plot/cimg_renderer.cpp` 中出现**。

**检查方法**：`grep -rn "0.5 \* .*width\|0.5f \* .*w\[" src/ --include=*.cpp`
的结果只能出现在 `io/`、`plot/`、`db/`（派生函数实现）三处。

### 铁律 3：纯 SoA，禁止 AoS 副本

- 不存在 `class Module { float x, y, w, h; ... }` 这样**持有数据**的类。
- 允许 `ModuleRef`（见 §3.3），但它**只持有 `PlaceDB&` 与 `int`**，不得有其他成员。
- 热路径（`init/`、`gp/`、`lg/` 的内层循环）**禁止**使用 `ModuleRef`，
  必须直接操作裸数组指针。

```cpp
// ❌ 禁止：热路径用句柄
for (int i = 0; i < n; ++i) { auto m = db.node(i); sum += m.width(); }

// ✅ 正确：热路径用裸数组
const float* __restrict w = db.node_w.data();
#pragma omp parallel for reduction(+:sum)
for (int i = 0; i < n; ++i) sum += w[i];
```

### 铁律 4：热路径禁止按值传递容器

任何在迭代循环中被调用的函数，参数与返回值**不得**是 `std::vector`（按值）。
一律用 `const T*` / `T*` + 长度，或 `std::span`（C++20）。

```cpp
// ❌ 禁止（easyPlace 的错误，每轮浪费 50 MB 拷贝）
std::vector<Vec2> getGradient();
void setPosition(std::vector<Vec2> pos);

// ✅ 正确
void computeGradient(const float* pos, float* grad, int n) const;
```

### 铁律 5：数值内核走 Backend Strategy

`numeric/` 下每个内核必须是"纯 C++ 抽象接口 + 工厂"。接口头文件**不得**
`#include <cuda_runtime.h>`、不得有 `#ifdef ENABLE_CUDA` 分支。

### 铁律 6：优化器只认 `obj_and_grad_fn`

优化器不得 `#include` `gp/` 或 `db/`。它只通过 §4.4 的回调契约与外界通信。

### 铁律 7：可复现

- 密度累加**必须**用 per-thread 局部网格 + **固定顺序**规约，**禁止**原子加法。
- 所有随机来源统一走 `Config::random_seed` 驱动的 `std::mt19937`，
  **禁止**使用 `rand()`、`std::random_device`、时间种子。
- 同一输入 + 同一配置的两次 CPU 运行必须**逐位一致**。
- 例外：CUDA 后端（M7）不保证逐位一致，须在日志中标注。

### 铁律 8：X/Y 方向不得复制粘贴

任何同时处理 x 与 y 的逻辑，**必须**抽成带方向参数的函数或模板，
**禁止**写两段结构相同的代码。

```cpp
// ❌ 禁止：easyPlace 正是这样漏改，导致 Y 方向 B2B 模型失效（见 §8.1）
if (pin1 == net.boundXmin || pin2 == net.boundXmax) { /* x 逻辑 */ }
if (pin2 == net.boundYmin || pin1 == net.boundYmax) { /* y 逻辑，改漏了 */ }

// ✅ 正确
enum class Axis { X, Y };
template <Axis A> void accumulateB2B(...);
accumulateB2B<Axis::X>(...);
accumulateB2B<Axis::Y>(...);
```

### 2.2 CMake 规范

```cmake
cmake_minimum_required(VERSION 3.20)

set(CMAKE_EXPORT_COMPILE_COMMANDS ON)

find_package(OpenMP REQUIRED)

# 核心库：所有逻辑都在这里
add_library(superplace STATIC ${SUPERPLACE_SOURCES})
target_link_libraries(superplace PUBLIC OpenMP::OpenMP_CXX)
target_compile_options(superplace PRIVATE
    -Wall -Wextra -Wno-unused-parameter
    $<$<CONFIG:Release>:-O3 -funroll-loops>
)
if(ENABLE_NATIVE)
    target_compile_options(superplace PRIVATE -march=native)
endif()

if(ENABLE_CUDA)
    enable_language(CUDA)
    set(CMAKE_CUDA_ARCHITECTURES 89)      # RTX 4060 = Ada, sm_89
    target_compile_definitions(superplace PUBLIC ENABLE_CUDA)
    target_sources(superplace PRIVATE src/numeric/cuda/cuda_poisson.cu)
endif()

add_executable(superplace-cli   src/main.cpp)
add_executable(superplace-check tools/check/main.cpp)
target_link_libraries(superplace-cli   PRIVATE superplace)
target_link_libraries(superplace-check PRIVATE superplace)   # 见 §4.6 注意事项
```

**硬性要求**：

| 要求 | 说明 |
| --- | --- |
| **必须** `-Wall -Wextra` | 禁止像 easyPlace 那样用 `-w`，它掩盖过真实缺陷 |
| **禁止** `-ffast-math` | 破坏浮点语义与逐位可复现性（铁律 7） |
| **禁止** `-fpermissive` | 掩盖类型错误 |
| **必须** `-fopenmp` | 铁律 3 的前提 |
| 依赖策略 | CImg 直接 vendor 到 `third_party/`（单头文件）；Eigen 用 `find_package` 或 `FetchContent`；FFT 优先 vendor `fftsg`，避免外部依赖 |

## 3. 核心数据结构

### 3.1 几何基础类型

```cpp
// src/db/geometry.h
#pragma once
namespace sp {

struct Point { float x = 0.f, y = 0.f; };

struct Rect {
    float lx = 0.f, ly = 0.f, hx = 0.f, hy = 0.f;   // low/high x/y
    float width()  const { return hx - lx; }
    float height() const { return hy - ly; }
    float area()   const { return width() * height(); }
};

/// 两矩形重叠面积。无重叠返回 0。全项目唯一的重叠面积实现。
inline float overlapArea(const Rect& a, const Rect& b) {
    const float dx = std::min(a.hx, b.hx) - std::max(a.lx, b.lx);
    const float dy = std::min(a.hy, b.hy) - std::max(a.ly, b.ly);
    return (dx > 0.f && dy > 0.f) ? dx * dy : 0.f;
}

} // namespace sp
```

> **注意**：`tools/check` **不得**复用此函数（铁律见 §4.6），须自行实现一份。

### 3.2 PlaceDB（纯 SoA + CSR）

```cpp
// src/db/place_db.h
#pragma once
#include <vector>
#include <string>
#include <cstdint>
#include "geometry.h"

namespace sp {

// 节点标志位
enum NodeFlag : uint8_t {
    F_MACRO  = 1u << 0,   // 宏单元（高度 != 行高，或 .nodes 中显式标注）
    F_FIXED  = 1u << 1,   // 固定（.pl 中带 /FIXED，或 .nodes 中标 terminal）
    F_FILLER = 1u << 2,   // 填充单元（全局布局阶段生成）
    F_NI     = 1u << 3,   // terminal_NI（零面积 IO 引脚，密度计算须跳过）
};

class PlaceDB {
public:
    // ---------- 节点几何：全部 SoA，索引 [0, numNodes) ----------
    // 约定：node_x / node_y 存储【中心坐标】（铁律 2）
    std::vector<float>   node_x, node_y;
    std::vector<float>   node_w, node_h;
    std::vector<uint8_t> node_flags;
    std::vector<std::string> node_name;    // 仅 IO / 调试，禁止进热路径

    // ---------- 引脚 ----------
    std::vector<float> pin_offset_x, pin_offset_y;   // 相对所属节点【中心】
    std::vector<int>   pin2node;                     // pin -> node

    // ---------- 超图 CSR ----------
    // net k 的引脚: flat_net2pin[net2pin_start[k] .. net2pin_start[k+1])
    std::vector<int> flat_net2pin,  net2pin_start;
    // node i 的引脚: flat_node2pin[node2pin_start[i] .. node2pin_start[i+1])
    std::vector<int> flat_node2pin, node2pin_start;
    std::vector<float> net_weight;                   // .wts，缺省全 1.0

    // ---------- 布局行 ----------
    struct SiteRow {
        float ly, height;      // 行底 y 与行高
        float lx, step;        // 起始 x 与 site 步长
        int   numSites;
        float hx() const { return lx + step * numSites; }
    };
    std::vector<SiteRow> rows;

    // ---------- 区域 ----------
    Rect coreRegion;    // 所有 SiteRow 的最小外包
    Rect chipRegion;    // coreRegion ∪ 所有固定节点，仅用于绘图
    float rowHeight = 0.f;    // 众数行高
    float totalRowArea = 0.f;

    // ---------- 分区索引 ----------
    // 约定：节点按 [可移动 | 固定] 分段排列，便于热路径直接切片
    int numMovable = 0;      // [0, numMovable)            可移动（含宏）
    int numNodes   = 0;      // [numMovable, numNodes)     固定
    int numFillers = 0;      // [numNodes, numNodes+numFillers)  填充单元
    int numPins    = 0;
    int numNets    = 0;

    int totalNodes() const { return numNodes + numFillers; }

    // ---------- 派生查询（唯一允许做中心↔角点换算的地方）----------
    float llx(int i) const { return node_x[i] - 0.5f * node_w[i]; }
    float lly(int i) const { return node_y[i] - 0.5f * node_h[i]; }
    float urx(int i) const { return node_x[i] + 0.5f * node_w[i]; }
    float ury(int i) const { return node_y[i] + 0.5f * node_h[i]; }
    Rect  box(int i) const { return {llx(i), lly(i), urx(i), ury(i)}; }
    float area(int i) const { return node_w[i] * node_h[i]; }

    bool isMacro (int i) const { return node_flags[i] & F_MACRO;  }
    bool isFixed (int i) const { return node_flags[i] & F_FIXED;  }
    bool isFiller(int i) const { return node_flags[i] & F_FILLER; }
    bool isNI    (int i) const { return node_flags[i] & F_NI;     }

    /// 引脚绝对坐标 = 所属节点中心 + 偏移
    float pinX(int p) const { return node_x[pin2node[p]] + pin_offset_x[p]; }
    float pinY(int p) const { return node_y[pin2node[p]] + pin_offset_y[p]; }

    // ---------- 构建（仅 io 层调用）----------
    void reserveNodes(int n);
    int  addNode(std::string name, float w, float h, uint8_t flags);
    void finalizeCSR();     // 见 §5.1.3，两趟构建
    void computeRegions();  // 计算 coreRegion / chipRegion / rowHeight
};

} // namespace sp
```

**关键约定**（Agent 必须遵守）：

| 约定 | 理由 |
| --- | --- |
| 节点按 `[可移动 \| 固定 \| filler]` 分段 | 热路径可直接对 `[0, numMovable)` 切片，无需逐个判标志位 |
| `pin_offset_*` 相对**中心** | 与 `.nets` 文件语义一致（见 §8.3 勘误） |
| `net_weight` 缺省填 1.0 | `.wts` 为空时也要保证数组长度正确 |
| 坐标用 `float` 而非 `double` | 与 DREAMPlace 一致（`dtype: float32`）；ISPD 坐标范围 < 1e6，float 精度足够；内存减半、SIMD 宽度翻倍 |

### 3.3 句柄视图（仅供非热路径使用）

```cpp
// src/db/module_ref.h
#pragma once
#include "place_db.h"

namespace sp {

class PinRange {                          // CSR 切片，可 range-for
    const int* b_; const int* e_;
public:
    PinRange(const int* b, const int* e) : b_(b), e_(e) {}
    const int* begin() const { return b_; }
    const int* end()   const { return e_; }
    int size() const { return int(e_ - b_); }
};

/// 只持有引用 + 索引，sizeof == 16，无堆分配，全 inline。
/// 用途：解析、IO、绘图、调试、答辩演示。禁止用于热路径（铁律 3）。
class ModuleRef {
    const PlaceDB& db_;
    int i_;
public:
    ModuleRef(const PlaceDB& db, int i) : db_(db), i_(i) {}
    int   index()   const { return i_; }
    const std::string& name() const { return db_.node_name[i_]; }
    float x()       const { return db_.node_x[i_]; }
    float y()       const { return db_.node_y[i_]; }
    float width()   const { return db_.node_w[i_]; }
    float height()  const { return db_.node_h[i_]; }
    Rect  box()     const { return db_.box(i_); }
    bool  isMacro() const { return db_.isMacro(i_); }
    bool  isFixed() const { return db_.isFixed(i_); }
    PinRange pins() const {
        return { db_.flat_node2pin.data() + db_.node2pin_start[i_],
                 db_.flat_node2pin.data() + db_.node2pin_start[i_ + 1] };
    }
};

} // namespace sp
```

## 4. 模块契约

### 4.1 阶段统一接口

```cpp
// src/stage.h
#pragma once
namespace sp {

class PlacementStage {
public:
    virtual ~PlacementStage() = default;
    /// 读写 db；每轮指标推给 sink；参数从 cfg 取。
    virtual void run(PlaceDB& db, const Config& cfg, MetricsSink& sink) = 0;
    virtual const char* name() const = 0;
};

} // namespace sp
```

`main.cpp` 只做三件事：解析 CLI → 按 `--stage` 组装 `std::vector<std::unique_ptr<PlacementStage>>`
→ 依次 `run` 并在每阶段后落 `.pl` + `.png` 快照。

**阶段之间禁止直接依赖**——`gp/` 不得 `#include` `init/`。

### 4.2 数值内核后端（铁律 5）

### 5.3 聚类驱动初始布局（任务 4-2）

**思想**：分而治之——先把节点聚成簇，簇作为质点定位，再在簇内摆放。

```
步骤 1：初始化每个可移动节点为独立簇
步骤 2：基于网表构建簇间连接权重
        w(a,b) = Σ over nets connecting a,b of  net_weight / (degree - 1)
步骤 3：迭代合并权重最大的簇对，更新权重与质心
        直到 簇数 <= target_cluster_count
步骤 4：簇内布局
        按簇面积在质心周围划矩形框，均分为 ceil(sqrt(n)) × ceil(sqrt(n)) 格
        节点依次放入格中心
```

**参数**：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `cluster.target_count` | `sqrt(numMovable)` | 停止条件 |
| `cluster.max_degree` | 100 | 跳过超大 net（degree > 此值不计权重，避免 O(d²) 爆炸） |

**验证**：所有节点在 coreRegion 内；HPWL 应显著优于随机布局（预期至少好 30%）。

**陷阱**：net degree 可达 2271（adaptec1），朴素地对每个 net 枚举所有引脚对是 O(d²)，
2271² ≈ 500 万次/net。**必须**设 `max_degree` 阈值跳过。

### 5.4 二次解析布局（任务 4-3，Kraftwerk2 B2B）

这是三种初始布局里唯一有实用价值的，也是任务 5 的初值来源。

#### 5.4.1 数学定义

目标函数（B2B 网络模型）：

$$\Gamma_x = \frac{1}{2}\sum_{n\in N}\sum_{p<q\in n} w^{B2B}_{x,pq}\,(x_p^{pin}-x_q^{pin})^2$$

$$w^{B2B}_{x,pq}=\begin{cases}0, & p,q\ \text{均为内部引脚}\\[4pt] \dfrac{1}{P-1}\cdot\dfrac{1}{|x_p^{pin}-x_q^{pin}|}, & \text{其他}\end{cases}$$

其中 \(P\) 为该 net 的引脚数，**边界引脚**指该 net 中 x 取最小/最大的两个引脚。
只有涉及边界引脚的 pin 对才有权重，故每个 net 恰好产生 \(2P-3\) 对。

> **为什么这样能精确拟合 HPWL**：\(2P-3\) 项求和后各项**伸缩相消（telescoping）**，
> 分母 \(P-1\) 被精确约掉，二次型之和严格等于 \(x_{max}-x_{min}\)。
> （注：`note/A` 原文称"组合对数为 P-1"是错的，已勘误。）

令未知量为**可移动节点中心坐标**，求驻点得线性方程组：

$$A_x\,\mathbf{x} = \mathbf{rhs}_x,\qquad A_y\,\mathbf{y} = \mathbf{rhs}_y$$

#### 5.4.2 矩阵装配（三种情况）

设 pin \(p\) 属节点 \(i\)、pin \(q\) 属节点 \(j\)，权重 \(w\)：

| 情况 | A 的贡献 | rhs 的贡献 |
| --- | --- | --- |
| i, j 均可移动 | `A[i][i]+=w; A[j][j]+=w; A[i][j]-=w; A[j][i]-=w` | `rhs[i] += -w*(off_i - off_j)`<br>`rhs[j] += -w*(off_j - off_i)` |
| i 可移动，j 固定 | `A[i][i] += w` | `rhs[i] += w*(pinX(q) - off_i)` |
| i 固定，j 可移动 | `A[j][j] += w` | `rhs[j] += w*(pinX(p) - off_j)` |
| i == j（同节点） | **跳过** | **跳过** |

其中 `off_i` 是 pin `p` 相对节点中心的偏移，`pinX(q)` 是固定引脚的绝对坐标。

#### 5.4.3 求解流程

```
moveAllMovableCentersTo(coreRegion.center)      // 第二步：统一移到中心
x0 = 当前中心坐标                                // BiCGSTAB 初值

for iter in 0..maxIter:
    updateNetBoundPins()                        // 重算每个 net 的 4 个边界引脚
    assemble(A_x, rhs_x, A_y, rhs_y)            // 用当前位置算权重
    x = BiCGSTAB(A_x, rhs_x, guess=x)           // maxIterations(100)
    y = BiCGSTAB(A_y, rhs_y, guess=y)
    writeBackAndClampToCore()                   // 夹回 coreRegion
    hpwl = computeHPWL()
    sink.push({iter, hpwl, xErr, yErr, ...})
    if (xErr < tol && yErr < tol && iter > 4) break
    if (iter >= maxIter) break
```

#### 5.4.4 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `qp.max_iter` | 20 | 外层迭代（权重依赖位置，须迭代） |
| `qp.tol` | 1e-6 | BiCGSTAB 残差阈值 |
| `qp.solver_max_iter` | 100 | 单次 BiCGSTAB 上限 |
| `qp.min_distance` | 1.0 | 权重分母下限，防止奇异 |

#### 5.4.5 实现要求

- 用 `Eigen::SparseMatrix<float, Eigen::RowMajor>`（即 CSR）+ `Triplet` 批量装配，
  **禁止**逐个 `insert()`。
- `tripletList.reserve(estimated_nnz)` 预留，估算 `nnz ≈ 4 * Σ(2*degree-3)`。
- 用 `solveWithGuess(rhs, x_prev)`，上一轮位置是最好的初值。
- **权重分母必须有下限**：`w = 1/(P-1) / max(|Δx|, MIN_DISTANCE)`，
  否则引脚重合时权重爆炸，BiCGSTAB 震荡不收敛。
- 每轮夹回边界：
  ```
  x = clamp(x, core.lx + 0.5*w + EPS, core.hx - 0.5*w - EPS)
  ```

#### 5.4.6 验证判据

- adaptec1 上 HPWL 应从初始（全在中心）的极大值单调下降并收敛；
  参考量级：收敛后 HPWL ≈ 2.5e8 ~ 3.5e8（具体值取决于实现细节，
  重点看**单调下降且稳定**，不要求与任何实现完全一致）。
- 与 easyPlace 对拍：同 benchmark 下 HPWL 差异应在 ±10% 以内。
  若差异巨大，优先怀疑边界引脚判定（见下）。

#### 5.4.7 ⚠️ 头号陷阱：X/Y 边界引脚判定

**easyPlace 在此处有确认的 bug**（`QPlace/qplace.cpp:157`）：Y 方向的判定条件写成了
`pin2==Ymin || pin1==Ymax || pin2==Ymin || pin2==Ymax`——第三项与第一项重复，
而 **`pin1 == boundPinYmin` 整个丢失**，导致约一半的「Ymin ↔ 内部引脚」配对被跳过，
B2B 的伸缩相消恒等式在 Y 方向失效。

**本项目按铁律 8 强制要求用模板/方向参数消除重复**：

```cpp
template <Axis A>
void QuadraticPlacer::accumulate(int net, ...) {
    const int bmin = boundPinMin<A>(net);
    const int bmax = boundPinMax<A>(net);
    for (int a = 0; a < deg; ++a)
      for (int b = a + 1; b < deg; ++b) {
        const int p = pins[a], q = pins[b];
        if (db.pin2node[p] == db.pin2node[q]) continue;         // 同节点跳过
        if (p != bmin && p != bmax && q != bmin && q != bmax) continue;  // 都是内部引脚
        /* ... 装配 ... */
      }
}
```

### 5.5 ePlace 全局布局（任务 5）

本节是全项目最复杂、最易错的部分。**严格按此规格实现，不要参考 easyPlace 的细节**
（它在宏单元密度缩放上有已确认的不自洽，见 §8.4）。

#### 5.5.1 总目标

$$f(\mathbf{v}) = \mathrm{WL}(\mathbf{v}) + \lambda\, D(\mathbf{v})$$

λ 由小到大动态调度，前期重线长、后期重密度。

#### 5.5.2 Filler 初始化

```
// 1. 空白面积
totalRowArea   = Σ rows[r].width * rows[r].height
overlapArea    = Σ over 固定节点 f (跳过 F_NI):
                     Σ over rows r: overlapArea(box(f), rowRect(r))
whitespaceArea = totalRowArea - overlapArea

// 2. 可移动节点缩放面积
cellArea  = Σ area(i)  for i in [0,numMovable) if !isMacro(i)
macroArea = Σ area(i)  for i in [0,numMovable) if  isMacro(i)
nodeAreaScaled = cellArea + macroArea * targetDensity

// 3. Filler 总面积与单个尺寸
totalFillerArea = whitespaceArea * targetDensity - nodeAreaScaled
areas = sorted([area(i) for i in [0,numMovable)])
lo = int(0.10 * numMovable);  hi = int(0.90 * numMovable)      // 中间 80%
fillerArea   = mean(areas[lo:hi])
fillerHeight = rowHeight
fillerWidth  = fillerArea / fillerHeight

// 4. 数量（注意括号！）
fillerCount = max(0, int(totalFillerArea / fillerArea + 0.5))   // 四舍五入 + 下界保护

// 5. 随机撒点（走统一 RNG）
```

**两处必须注意**：

1. **中间 80%，不是 90%。** ePlace 论文 §3.2 原文是 "mid-80% of movable cells"。
   easyPlace 取的是 5%~95%（即 90%），课程笔记的"90%"说法来源于此，**以论文为准**。
2. **`fillerCount` 的括号**：是 `(totalFillerArea / fillerArea) + 0.5`（四舍五入），
   **不是** `totalFillerArea / (fillerArea + 0.5)`。课程笔记此处误加括号，已勘误。
3. **必须加 `max(0, ...)`**：拥挤设计下 `totalFillerArea` 会为负，
   直接 `resize(负数)` 会转成巨大 `size_t` 导致崩溃（easyPlace 无此保护）。

#### 5.5.3 Bin 网格初始化

```
avgArea     = (cellArea + macroArea) / numMovable
idealBinArea = avgArea / targetDensity
idealCount   = coreArea / idealBinArea
// 取 2 的幂，使 (2^i)^2 <= idealCount < (2^(i+1))^2
binDim = 2^i, 上限 1024
step_x = coreRegion.width()  / binDim
step_y = coreRegion.height() / binDim
```

对每个 bin 预计算两个**只算一次**的量：

| 量 | 公式 | 说明 |
| --- | --- | --- |
| `terminalDensity[b]` | `Σ over 固定节点 f (在 core 内, 非 NI): targetDensity * overlapArea(bin_b, box(f))` | 固定单元的阻塞 |
| `baseDensity[b]` | `targetDensity * (bin_b.area - Σ_r overlapArea(bin_b, row_r))` | 不可放置区域的等效密度 |

> **性能要求**：`baseDensity` 的朴素实现是 `bins × rows` 双重循环，
> adaptec1 上是 512×512×890 ≈ 2.3 亿次求交。**必须**按 y 坐标为 rows 建索引，
> 每个 bin 只遍历与其 y 区间相交的行。

> **命名统一**：本项目统一用 `baseDensity`（不用 `darkDensity`），
> 与 RePlAce / DREAMPlace 一致。课程材料 5 两处命名不一致，已勘误。

#### 5.5.4 每轮：密度统计

```
清零 nodeDensity / fillerDensity（全部 bin）

for each node i in [0, numNodes + numFillers):
    if isFixed(i) or isNI(i): continue

    // local smoothing：小于一个 bin 的单元虚拟放大到 bin 尺寸
    rect = box(i);  scale = {1,1}
    if (w[i] < step_x) { scale.x = w[i]/step_x;
                         rect.lx = cx - 0.5*step_x; rect.hx = cx + 0.5*step_x; }
    if (h[i] < step_y) { scale.y = h[i]/step_y;
                         rect.ly = cy - 0.5*step_y; rect.hy = cy + 0.5*step_y; }

    for each bin b overlapping rect:
        ov = overlapArea(bin_b, rect) * scale.x * scale.y
        if      isFiller(i): fillerDensity[b] += ov
        else if isMacro(i):  nodeDensity[b]   += ov * targetDensity   // 密度缩放
        else:                nodeDensity[b]   += ov
```

**密度缩放规则（务必记牢）**：乘 `targetDensity` 的只有**宏单元、固定终端、暗节点**。
标准单元和 filler **不乘**（filler 的总面积本身就是按目标密度设计的）。

**并行要求**（铁律 7）：多线程往同一 bin 累加，**必须**用 per-thread 局部网格 +
固定顺序规约，**禁止**原子加法（既慢又破坏可复现性）。

#### 5.5.5 每轮：泊松求解

送入后端的电荷密度：

$$\rho_b = \frac{\text{nodeDensity}_b + \text{fillerDensity}_b + \text{terminalDensity}_b + \text{baseDensity}_b}{A_b}$$

后端内部（`CpuPoissonBackend::solve`）：

```
1. DCT 正变换:  a[j][k] = DCT2(ρ)
2. 去 DC:       a[0][0] = 0                       // Neumann 边界下方程可解的前提
3. 频域求解:    ψ[j][k] = a[j][k] / (w_j² + w_k²),  w_j = jπ/m,  w_k = kπ/m
                （j==0 && k==0 时置 0）
4. 反变换得电势: φ = IDCT2(ψ)
5. 电场（注意用 sin/cos 混合变换，即 IDXST/IDCT 组合）:
   ξ_x(x,y) = Σ_j Σ_k  a[j][k] * w_j / (w_j²+w_k²) * sin(w_j x) cos(w_k y)
   ξ_y(x,y) = Σ_j Σ_k  a[j][k] * w_k / (w_j²+w_k²) * cos(w_j x) sin(w_k y)
```

**为什么用 DCT 而非普通 FFT**：余弦基天然满足 Neumann 边界条件
（\(\sin(w_j\cdot 0)=0\)、\(\sin(w_j L)=\sin(j\pi)=0\)，即电场在边界法向分量为 0），
单元不会被推出芯片。FFT 的复指数含正弦分量，在边界导数不为 0，不满足该条件。

#### 5.5.6 每轮：线长梯度（WA 模型）

对 net \(e\) 中的引脚 \(i\)：

$$a_i^{+}=e^{(x_i-x_e^{+})/\gamma},\quad b_e^{+}=\sum_{i\in e}a_i^{+},\quad c_e^{+}=\sum_{i\in e}x_i a_i^{+}$$
$$a_i^{-}=e^{-(x_i-x_e^{-})/\gamma},\quad b_e^{-}=\sum_{i\in e}a_i^{-},\quad c_e^{-}=\sum_{i\in e}x_i a_i^{-}$$

$$\frac{\partial \mathrm{WL}_e}{\partial x_i}=\frac{(1+\frac{x_i}{\gamma})b_e^{+}-\frac{1}{\gamma}c_e^{+}}{(b_e^{+})^2}a_i^{+}-\frac{(1-\frac{x_i}{\gamma})b_e^{-}+\frac{1}{\gamma}c_e^{-}}{(b_e^{-})^2}a_i^{-}$$

**数值稳定性（必须做）**：指数里减去 \(x_e^{+}\)（该 net 的最大值）与 \(x_e^{-}\)（最小值），
使指数项 ≤ 1，防止 `exp` 溢出。这不是可选优化，是正确性要求。

γ 的调度：

$$\gamma = 8\,w_b\cdot 10^{\frac{20}{9}(\tau-0.1)-1.0}$$

其中 \(w_b\) 是 bin 步长，\(\tau\) 是密度溢出率。额外分段处理：
τ > 1.0 时 γ 再乘 10；τ < 0.1 时 γ 再乘 0.1。

**性能要求**：先对所有 net 预计算 \(b_e^\pm, c_e^\pm\)（一趟），再对所有引脚求梯度（第二趟）。
两趟都可 `#pragma omp parallel for`。跳过 `degree > ignore_net_degree`（默认 100）的超大 net。

#### 5.5.7 每轮：总梯度组装（符号最易错处）

```
// densityForce[i] 是 DensityBackend::gatherForce 的输出，语义为 q·ξ
// 数学梯度 ∇D = -q·ξ，所以：
for each node i in [0, numNodes + numFillers):
    precond = 1.0 / max(1.0, numNetsOf(i) + lambda * area(i))

    if isFiller(i):
        grad[i] = precond * ( -lambda * densityForce[i] )   // filler 无线长梯度
    else:
        grad[i] = precond * ( wirelengthGrad[i] - lambda * densityForce[i] )
```

> **反复确认这里的符号。** `grad` 是数学梯度 \(\nabla f\)，优化器执行 `pos -= α·grad`。
> 密度力 \(q\xi\) 指向低密度方向（"推开"），而 \(\nabla D = -q\xi\)，
> 所以 `grad` 中密度项前是**减号**。若写成加号，单元会向高密度区聚集——
> 现象是"越跑越挤"，很容易被误判为 λ 太小。

**预条件子**的作用是让不同规模的模块步长一致：小单元、少连线更灵活；大宏、密连线更稳。

#### 5.5.8 密度溢出率 τ

$$\tau=\frac{\sum_{b\in B}\max\!\left(\rho'_b-\rho_t,\,0\right)\cdot A_b}{\text{cellArea}+\text{macroArea}\cdot\rho_t}$$

其中 \(\rho'_b = (\text{nodeDensity}_b+\text{terminalDensity}_b+\text{baseDensity}_b)/A_b\)，
**不含 fillerDensity**。

**必须取正部** \(\max(\cdot, 0)\)：否则稀疏 bin 的负溢出会抵消拥挤 bin 的正溢出，
且由于总面积守恒，τ 会近似为常数，完全失去作为停止判据的意义。

#### 5.5.9 λ 调度

初始化：

$$\lambda_0 = \frac{\sum_i |\nabla \mathrm{WL}_i|}{\sum_i |q_i\xi_i|}$$

（分子只累加真实节点，分母累加节点 + filler。目的是让两股力初始量级相当。）

每轮更新：

$$\lambda_k = \mu_k\lambda_{k-1},\qquad \mu_k = 1.1^{-\Delta \mathrm{HPWL}_k/\Delta \mathrm{HPWL}_{REF}+1.0}$$

`ΔHPWL_REF = 3.5e5`，`μ` 夹到 `[0.95, 1.05]`。HPWL 下降时（Δ<0）直接取上界 1.05。

#### 5.5.10 Nesterov 优化器

```
a_0 = 1;  u_0 = v_0 = pos_init
每步：
    g = ∇f(u_k)                                  // 通过 obj_and_grad_fn
    α_k = (k == 0) ? 1.0 : 1.0 / L_k
          L_k = ‖∇f(u_k) - ∇f(u_{k-1})‖ / ‖u_k - u_{k-1}‖     // Lipschitz 估计
    a_{k+1} = (1 + sqrt(4·a_k² + 1)) / 2
    v_{k+1} = u_k - α_k · g
    u_{k+1} = v_{k+1} + (a_k - 1)/a_{k+1} · (v_{k+1} - v_k)
    constraintFn(u_{k+1})                         // 夹回 coreRegion
```

**可选**：Barzilai-Borwein 步长（`use_bb`），取 `s·y/‖y‖²`，若为负则回退到 `min(‖s‖/‖y‖, 1/L)`。

#### 5.5.11 三层嵌套调度

**不要只写单层循环。** 按 DREAMPlace 的做法分三层，收敛显著更稳：

```
外层 Lgamma:     γ 调度（随 τ 下降而收紧线长平滑度）
  中层 Llambda:  λ 调度（密度权重递增）
    内层 Lsub:   实际的 Nesterov 下降步
```

停止条件：`τ < target_overflow` 或 `iter > max_iter`。
（easyPlace 只有单层，这是其收敛质量的短板之一。）

### 5.6 布局合法化（任务 7，选做）

#### 5.6.1 Abacus（标准单元）

```
1. 按 x 坐标排序所有可移动标准单元
2. for each cell i:
     c_best = ∞
     for each 候选行 r（取 y 最近的 K 行，K 默认 3~5）:
         试插 cell i 到行 r
         PlaceRow(r) 试算              // 行内二次规划，最小化总位移
         c = 位移代价
         if c < c_best: c_best = c, r_best = r
         撤销试插
     正式插入 r_best 并 PlaceRow(r_best)
```

`PlaceRow` 的核心是**簇（cluster）合并**：维护若干簇，每簇记 `x, e(权重和), q(加权位置和), w(总宽)`，
新单元加入时若与前一簇重叠则合并，簇最优位置 `x = q/e`，最后夹到行边界并对齐 site。

#### 5.6.2 宏单元（模拟退火）

目标：消除宏间重叠，同时控制线长增量。代价函数
`cost = α·overlapArea + β·ΔHPWL`。标准 SA 流程，随机移动/交换/翻转。

#### 5.6.3 验证

用 `superplace-check` 验收：重叠 0、越界 0、全部对齐到 row 与 site。

## 8. 陷阱清单（必读）

以下每一条都是**已确认**的坑，来源为 easyPlace 代码审查与课程资料勘误。

### 8.1 【致命】X/Y 方向复制粘贴

easyPlace `QPlace/qplace.cpp:157` 的 Y 方向边界判定漏了 `pin1 == boundPinYmin`，
且有一项重复。**不会崩溃、不会报错**，只表现为 Y 方向布局质量偏差，极难发现。
→ 铁律 8 强制用模板消除。

### 8.2 【致命】密度梯度符号

`∇D = -q·ξ`。总梯度里密度项前是**减号**。写成加号会让单元向高密度区聚集。
→ §5.5.7，并在 `DensityBackend::gatherForce` 的文档注释中锁死"返回的是力不是梯度"。

### 8.3 【高】pin 偏移的来源与基准

- 偏移定义在 **`.nets`** 文件（不是 `.scl`，课程材料此处笔误已勘误）。
- 偏移是相对节点**中心**，不是左下角。

### 8.4 【高】宏单元密度缩放不自洽

easyPlace 在密度统计时对宏乘了 `targetDensity`（`eplace.cpp:952`），
但在密度梯度里没乘（`eplace.cpp:560`，作者自己打了一串问号）。
**场缩放了、力不缩放** = 混合尺寸模式下宏的受力与其密度贡献不自洽。
→ 本项目要求两处**一致**。若统计时乘了 ρ_t，取力时电荷量 q 也必须用缩放后的面积。

### 8.5 【高】每轮重建 FFT 对象

easyPlace `eplace.cpp:465` 每次 `densityGradientUpdate()` 都新建 `FFT_2D`，
512×512 下每轮浪费 4 MB 分配 + 三角函数表重算。
→ 后端对象在初始化时构造一次并持有（§4.2）。

### 8.6 【高】filler 数量为负

拥挤设计下 `totalFillerArea < 0`，`resize(负数)` 会转成巨大 `size_t` 而崩溃。
→ `max(0, ...)` 保护（§5.5.2）。

### 8.7 【中】filler 尺寸取中间 80% 还是 90%

论文是 **80%**（10%~90%）。easyPlace 取 5%~95%（90%），课程笔记沿用了它。
→ 以论文为准，取 80%。

### 8.8 【中】filler 数量公式的括号

`(int)(totalFillerArea / fillerArea + 0.5)` 是**四舍五入**，
不是 `totalFillerArea / (fillerArea + 0.5)`。课程笔记误加括号，已勘误。

### 8.9 【中】τ 必须取正部

不取 `max(·,0)` 的话，τ 会因面积守恒而近似为常数，失去停止判据的意义。

### 8.10 【中】WA 模型的指数溢出

不减去 `x_e^+` / `x_e^-` 直接算 `exp(x/γ)`，γ 较小时会溢出成 `inf`。
→ §5.5.6 的数值稳定性处理是**正确性要求**，不是优化。

### 8.11 【中】net degree 可达 2271

朴素的 O(d²) 引脚对枚举在 adaptec1 上会退化。
→ 二次布局与聚类布局都要设 `max_degree` 阈值。

### 8.12 【低】`.wts` 为空文件

adaptec 系列的 `.wts` 是空的，解析器须容错并填默认权重 1.0。

### 8.13 【低】`terminal_NI` 零面积节点

密度计算、绘图、whitespace 统计都要跳过，否则会引入零面积矩形导致除零。

### 8.14 【低】现有 benchmark 无可移动宏

`test_data/` 三个 benchmark 的 macro 计数**均为 0**。这是数据特性不是 bug。
混合尺寸相关代码路径（宏密度缩放、宏合法化、mGP/cGP 切换）**在这些数据上不会被执行**，
必须用 MMS 才能验证。
