================================================================================
superPlace  环境依赖清单
================================================================================

记录本项目需要额外安装的包与环境。仓库自带的依赖、系统已有的依赖也一并列出，
以便区分「必须装什么」和「不用管什么」。

验证环境：Ubuntu 24.04.1 LTS on WSL2 (kernel 5.15.153.1-microsoft-standard-WSL2)
最后更新：2026-09-10（M1 完成时）


================================================================================
一、一键安装（当前项目全部所需）
================================================================================

    sudo apt update
    sudo apt install -y \
        pkgconf libpng-dev libeigen3-dev libfftw3-dev \
        ninja-build ccache \
        python3-numpy python3-matplotlib python3-pil

合计新增磁盘占用约 70 MB。

注意：Ubuntu 24.04 启用了 PEP 668，Python 包必须走 apt，不能用 pip 装到系统环境，
      否则报 externally-managed-environment。

================================================================================
七、WSL2 特有注意事项
================================================================================

图形加速（只有做 GUI 查看器时才相关）
--------------------------------------------------------------------------------
WSLg 默认使用 llvmpipe 软件渲染（Accelerated: no），画 21 万个矩形会卡。
本机其实有 RTX 4060 且 mesa 的 d3d12 驱动已安装，只是没被选为默认。
启用硬件加速：

    export GALLIUM_DRIVER=d3d12

    验证：glxinfo -B | grep -E "Device|Accelerated"
    期望：Device: D3D12 (NVIDIA GeForce RTX 4060 Laptop GPU) / Accelerated: yes

建议写进 ~/.bashrc。注意 glxinfo 需要 mesa-utils（sudo apt install mesa-utils）。

命令行输出编码
--------------------------------------------------------------------------------
通过 python.exe 调用 Windows 侧 Python 时，stdout 是 GBK 编码，
打印 emoji 会抛 UnicodeEncodeError。本项目脚本一律用 WSL 内的 python3。
